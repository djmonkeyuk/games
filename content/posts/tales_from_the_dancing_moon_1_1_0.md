# 🛠️ Version 1.1
## Updates
* Updated Unreal Engine version to 5.7.4
* Updated SteamSDK version.
* Leaderboard UI's now show the player's Steam avatar alongside their name.
* Adjusted text on the sleep tips.
* Changed the graphic of the removal crosshair in build mode.
* Increased the speed of the character customisation sliders when using gamepad.
* Implemented a loading screen and spin-wheel graphic for level transitions.
* Increased character turn speed in the character creation level.
* Adjust and rebaked lighting in all levels.
* Adjusted wetness shader on environment when raining.
* Adjusted material settings on ocean and rivers.
* Updated the controller mapping window in settings.
* Updated atmospheric fog settings in Worm's Tail region.

## Bugfixes
* Fixed a z-order issue between the landscape and the river in Illisor Plaza.
* Fixed an incorrect gamepad scrolling behavior on the character creation screen.
* Fixed an issue where the equipped item button hint UI would disappear after level transitions.
* Fixed a text overflow and scrollbar issue on the map screen.
* Fixed an issue where you could not scroll up on the map description UI.
* Fixed a text cropping issue on crafting menus.
* Fixed an issue where gamepad buttons would not register on warning dialog boxes when interacting with storage boxes.
* Fixed a rendering issue with particular carpet meshes.
* Fixed an issue where the UI overlays in the 'Tiles from The Dancing Moon' mini-game would lag behind the camera movement.
* Fixed an issue where any mouse clicks would not register during the "fade to black" transitions.
* Fixed a rare issue where unintended weather effects would play in scenes where weather should not apply.
* Fixed an issue where the right thumbstick would not scroll on certain windows.
* Fixed a rare issue where the player could fall off the map in the Town Hall - Ground Floor.
* Fixed a UI blocking issue when using touch screen interfaces.
* Minor text changes and typo fixes.

## Optimizations∏
* Updated TemporalAA configuration settings to reduce ghosting artefacts during onscreen movement.
* Optimized the logic when initiating crafting menus.
* Optimized logic when gathering world resources from enemies or harvestables (trees, rocks, blobs, etc)
* Optimized logic when initiating a dig using the shovel.
* Optimized performance of weather effects.
* Significantly reduced the memory load on texture assets.
* Significantly reduced the overall file size of the game.
* Significantly optimized the generation of Nav-Meshes when entering a level.
* Other miscellaneous logic performance optimizations.
* All latest updates and fixes have been rolled into the Demo version of the game. 🐝
